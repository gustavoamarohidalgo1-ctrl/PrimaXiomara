AGENCIA DE EMPLEOS S.T SERVITOTAL - Windows y Mac
================================================
Version de distribucion para Windows: 1.7.2 (el paquete de Mac sigue en 1.7.1).

WINDOWS: ZIP SIN INSTALAR (RECOMENDADO)
  Servitotal-1.7.2-Windows-portable.zip incluye Python y todos los recursos.
  1. Antes de extraer: clic derecho sobre el ZIP > Propiedades > marque
     "Desbloquear" (si aparece) > Aceptar.
  2. Clic derecho sobre el ZIP > Extraer todo (por ejemplo en Documentos).
  3. Abra la carpeta Servitotal-1.7.2 y haga doble clic en Servitotal.exe.
  Servitotal.exe es el Python oficial (pythonw.exe, firmado por Python
  Software Foundation) con otro nombre. El ZIP no tiene .bat ni ejecutables
  propios sin firma, asi que funciona tambien donde Windows 11 bloquea
  programas desconocidos. Conserve toda la carpeta.
  Acceso en el Escritorio: clic derecho en Servitotal.exe > Enviar a >
  Escritorio (crear acceso directo).
  Los datos se guardan en %LOCALAPPDATA%\Servitotal, igual que con el instalador.
  Si no abre, Diagnosticar Servitotal.exe muestra el error en una ventana.

DATOS DE LA VERSION ANTERIOR
  La version anterior guardaba agencia.db junto al programa. La primera vez que
  la version 1.7.2 se abre sin datos, busca ese archivo en el Escritorio,
  Documentos y Descargas (tambien en OneDrive) y pregunta si desea traerlo.
  Al aceptar, copia y actualiza los datos; el archivo original no se modifica.
  Si no lo encuentra: Ctrl+Shift+B > "Traer datos de otra carpeta..." y elija
  el agencia.db de la carpeta anterior. Cierre antes el programa anterior.

ABRIR CON PYTHON OFICIAL INSTALADO POR SEPARADO
  Servitotal-1.7.2-Windows-Python.zip contiene solo codigo, recursos y ayuda.
  Instale Python 3.14.7 completo: Windows installer (64-bit) de
  https://www.python.org/downloads/release/python-3147/
  Mantenga tcl/tk and IDLE, el lanzador y la asociacion de archivos con Python.
  No use el Python de Microsoft Store: guarda los datos en una carpeta privada.
  Extraiga todo el ZIP y abra Abrir Servitotal.pyw. No abra app/agencia.py.
  Este acceso usa %LOCALAPPDATA%\Servitotal, igual que la version instalada.
  Diagnosticar Servitotal.py muestra los errores si se ejecuta con Python.

TEMA OSCURO
  Fondos oscuros con detalles rosa y fucsia de Servitotal.
  El logo original y los colores de los botones se conservan.

ABRIR EN ESTA CARPETA
  Windows: doble clic en Iniciar.bat. Necesita Python 3.8 o posterior con
  tkinter y sqlite3. Si falta Python, descarguelo desde
  https://www.python.org/downloads/ y marque "Add Python to PATH" y
  "tcl/tk and IDLE". Copie TODOS los archivos juntos (agencia.py necesita
  contratos_servitotal.py); si falta alguno, Iniciar.bat lo avisa.
  Mac: doble clic en Crear_App_Mac.command para crear Servitotal.app.
  Este lanzador usa el Python instalado en este equipo (Tk 8.6 o posterior).
  Su minimo de macOS depende de ese Python y se muestra al crearlo.
  Deje Servitotal.app junto a agencia.py y contratos_servitotal.py.
  F11 activa pantalla completa; Esc permite salir de ella.

EXE PORTATIL PARA WINDOWS
  Crear_EXE.bat genera Servitotal.exe con su propio logo e iconos incluidos.
  Necesita internet para instalar PyInstaller en un entorno temporal aislado.
  Si falla una etapa, se detiene y muestra el error; no copia un EXE anterior.
  Conserve la base agencia.db junto al EXE para seguir usando los datos actuales.
  Si no hay base junto al EXE, los datos nuevos se guardan en la carpeta
  del usuario Servitotal indicada mas abajo.

INSTALADORES
  instaladores/Servitotal-Mac-arm64.dmg       Mac con chip Apple M1 o posterior.
  instaladores/Servitotal-Windows-x64.exe     Windows 10 u 11 de 64 bits.
  Estos paquetes incluyen Python: el equipo receptor no necesita instalarlo.
  El minimo de macOS se calcula a partir de los binarios incluidos y aparece
  en las instrucciones del DMG; no se promete compatibilidad inferior.
  Mac: abra el DMG y arrastre Servitotal a Aplicaciones. Si macOS no verifica
  al desarrollador, use clic derecho > Abrir o la opcion "Abrir igualmente"
  de Ajustes del Sistema > Privacidad y seguridad.
  Windows: abra el instalador; instala para el usuario actual sin administrador.
  Si aparece "Windows protegio su PC" de SmartScreen: el instalador todavia
  no tiene firma de editor. Si descargo Servitotal-Windows-x64.exe del
  repositorio oficial y confia en su procedencia, pulse "Mas informacion",
  compruebe el nombre y pulse "Ejecutar de todas formas".
  Si aparece "Control inteligente de aplicaciones bloqueo..." (Windows 11),
  ese aviso no permite continuar: use el ZIP recomendado de arriba.
  Repositorio: https://github.com/gustavoamarohidalgo1-ctrl/PrimaXiomara
  No hace falta desactivar Defender ni agregar exclusiones. Si se detecta un
  virus concreto, conserve el texto de Seguridad de Windows > Proteccion
  contra virus y amenazas > Historial de proteccion para revisarlo.
  En Propiedades, el instalador 1.7.2 completo ocupa {{BYTES_EXE}} bytes.
  Si la descarga quedo incompleta, descargue nuevamente el archivo completo.
  El instalador 1.7.2 se probo instalando sobre 1.7.1, abriendo el programa
  con su acceso del Escritorio, trayendo datos ficticios de la version
  anterior y desinstalando, en Windows Server 2022 y 2025. Esas pruebas no
  reproducen SmartScreen, antivirus ni la configuracion del equipo receptor.
  Los datos se guardan aparte del programa:
    Mac:      ~/Library/Application Support/Servitotal
    Windows:  %LOCALAPPDATA%\Servitotal
  Actualizar la aplicacion conserva esa carpeta. Al desinstalar en Windows,
  por defecto se conservan los datos; borrarlos requiere elegirlo expresamente.
  Los instaladores y sus datos tienen identidad propia para coexistir con
  el programa de Servicio Exclusivo.
  Para trasladar datos desde la carpeta original a una instalacion, vea
  DATOS DE LA VERSION ANTERIOR. No copie una base con el programa abierto.

SECCIONES Y FLUJO
  Clientes: pedido, datos personales, sueldo, horario, servicio y garantia.
  Trabajadoras: perfil, documentos, especialidad y disponibilidad.
  Los campos de servicio y especialidad admiten escribir y sugieren opciones.
  Areas: cree o elimine areas propias. Solo se elimina un area sin personas
  registradas en ella. Seleccione cliente y trabajadora y pulse Asignar.
  Revise las condiciones antes de confirmar; despues puede abrir el contrato,
  firmarlo, imprimirlo o deshacer la asignacion desde Ver asignaciones.
  Comisiones: admite un monto o un porcentaje del sueldo; al cambiar uno se
  calcula su equivalente. El 50 % es una propuesta inicial editable de
  Servitotal, no una comision obligatoria. Elija lo pactado en cada contrato.
  Puede registrar el pago y ver lo cobrado, lo pendiente y lo cobrado este mes.
  Ganancias: resumen de comisiones cobradas y pendientes, ingresos por area
  y ultimos pagos. No calcula ganancia neta porque no registra gastos.
  Garantias: la propuesta de Servitotal es 30 dias; se puede acordar otro
  plazo en dias o meses, o sin garantia. El contrato imprime el plazo elegido.
  Las pestanas separan pendientes, cerradas y sin garantia. Al solicitar
  reemplazo, el pedido vuelve a pendiente y la siguiente asignacion conserva
  la garantia pactada sin cobrar otra comision.

CONTRATOS Y FIRMAS
  La primera hoja conserva el contrato de servicio de Servitotal, con sus
  datos y condiciones propias; la segunda agrega el contrato de trabajo.
  Ambas usan las condiciones y firmas de la misma asignacion.
  Cada persona puede dibujar su firma en pantalla o usar Firmar con nombre
  en su recuadro, cuando esa persona acepte hacerlo de esa manera.
  Son firmas guardadas en el documento; no firmas digitales certificadas.
  Imprima o guarde el documento desde el navegador que lo abre.

GUARDADO Y RESPALDOS
  Pulse Guardar al completar los datos de una ficha. Los registros nuevos
  incompletos pueden conservarse como borradores y recuperarse con Nuevo.
  El programa genera respaldos al abrir, periodicamente si hubo cambios,
  al cerrar y antes de operaciones de borrado o restauracion.
  Ademas guarda copias externas y archivos CSV en:
    Documentos/Respaldos Servitotal
  Puede elegir otra carpeta, por ejemplo un USB o una carpeta sincronizada.
  Cmd+Shift+B en Mac o Ctrl+Shift+B en Windows abre el panel para hacer una
  copia, restaurarla, abrir las carpetas, configurar una carpeta adicional o
  traer los datos de otra carpeta (por ejemplo, el agencia.db de la version
  anterior).
  Conviene conservar tambien una copia en otro dispositivo.

ARCHIVOS PROPIOS

  agencia.db                 Base de datos; no sustituir por la de otra agencia.
  logo.png                   Logo original del menu lateral de Servitotal.
  icono.png / .ico / .icns    El mismo logo en formatos de icono.
  contratos/                 Contratos HTML generados.
  respaldos/                 Copias locales de seguridad.
  errores.log                Registro de errores, si se producen.
  respaldo_antes_actualizacion_20260929/  Copia del proyecto anterior.

VOLVER A GENERAR DISTRIBUCIONES
  Los scripts estan en instaladores/construccion:
    crear_instalador_mac.sh      Genera el DMG en un Mac Apple Silicon.
    crear_instalador_windows.sh  Genera el instalador Windows desde un Mac
                                con makensis, sevenzip y msitools.
    crear_iconos.sh              Convierte el logo original a formatos de
                                icono usando herramientas de macOS.
    crear_portable_windows.py    Crea el ZIP portable a partir del instalador
                                ya construido. Necesita Python y 7-Zip.
    crear_paquete_python.py      Crea el ZIP de codigo para Python oficial.
  Los scripts empacan el codigo actual y los recursos de esta carpeta.
  No incluyen la base de datos, contratos, respaldos ni datos personales.
  Si cambia el codigo, vuelva a generar los paquetes antes de distribuirlos.

AJUSTES EN agencia.py
  Nombre y eslogan, carpeta propia de datos, datos legales de Servitotal,
  moneda, propuesta de comision y plazo inicial de garantia.
  AGENCIA_CARPETA_DATOS debe seguir siendo Servitotal para mantener separados
  los datos y respaldos de las otras agencias.

ACTUALIZAR CON SEGURIDAD (VERSION 1.7.2)
  Guarde su trabajo y cierre el programa antes de actualizarlo en Mac o Windows.
  Windows comprueba si los archivos estan en uso y bloquea la actualizacion o
  desinstalacion si encuentra una instancia abierta o no puede verificarlo.
  Dos instaladores de la misma agencia no pueden ejecutarse a la vez.
  Los archivos nuevos se preparan por separado antes de reemplazar la version
  anterior. Si el antivirus los esta revisando, el cambio se reintenta durante
  unos segundos. Si aun asi falla, se intenta recuperar la version anterior. Si Windows
  tambien impide recuperarla, el mensaje indica donde quedaron los originales.
  La carpeta normal de datos se conserva; al desinstalar, borrarla sigue siendo
  una opcion explicita y la respuesta predeterminada es No.
  Si hay agencia.db, contratos, respaldos, configuracion.json, borradores.json
  o errores.log dentro de app/runtime, se detiene el cambio para conservarlos.
  Haga una copia y cambie esa ubicacion antes de actualizar o desinstalar.

CONSERVACION DE COPIAS Y CONTRATOS
  Una restauracion comprueba y actualiza una copia temporal antes de sustituir
  la base abierta. Conserva la base anterior si falla esa preparacion y guarda
  un resguardo si no puede completar la recuperacion.
  La misma base abierta, incluso con otro nombre o acceso directo, no se puede
  elegir como fuente de restauracion.
  Al actualizar, los contratos firmados anteriores se conservan como documento
  cuando las fichas relacionadas todavia existen. Corregir una ficha despues
  no reescribe ese documento. Un contrato sin sus personas conserva sus datos
  existentes y no inventa informacion para reconstruir un pasado desconocido.
